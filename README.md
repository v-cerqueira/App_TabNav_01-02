# App_TabNav_01

Aplicativo mobile desenvolvido com **React Native + Expo**, utilizando navegação por abas (Bottom Tab Navigation). O app serve como portfólio profissional de Vinicius Cerqueira Silva.

## Telas

| Aba | Descrição |
|-----|-----------|
| Home | Tela inicial de boas-vindas |
| Portfolio | Currículo completo com experiências, competências e formação |
| Contato | Informações de contato e formulário de mensagem |

## Tecnologias

- [React Native](https://reactnative.dev/) 0.85.3
- [Expo](https://expo.dev/) ~56.0.8
- [React Navigation — Bottom Tabs](https://reactnavigation.org/) ^7.16.2
- [React Native Vector Icons](https://github.com/oblador/react-native-vector-icons) ^10.3.0

## Como rodar

```bash
# Instalar dependências
npm install

# Iniciar o projeto
npm start

# Rodar no Android
npm run android

# Rodar no iOS
npm run ios

# Rodar na Web
npm run web
```

Após `npm start`, escaneie o QR Code com o app **Expo Go** no seu celular.
